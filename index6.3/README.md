
# Assignment 6.3 — Overflow & Layout Fixing

## Objective
To understand CSS overflow properties and fix layout overflow issues.

## Concepts Used
- overflow: visible
- overflow: hidden
- overflow: auto
- overflow: scroll
- Fixed-height containers
- Responsive layouts
- overflow-wrap: anywhere

## How to Run
1. Save index.html and style.css in the same folder.
2. Open index.html in your browser.
3. Scroll the Auto and Scroll boxes to view extra content.
4. Resize the browser to test the responsive layout.

## Layout Fix
The fixed layout uses max-width, min-width: 0,
box-sizing: border-box and overflow-wrap: anywhere
to help prevent long text from breaking the layout.
